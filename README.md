🌐 Multi-DNS & AdBlock Hosts Parser
Ультимативный инструмент для автоматизации создания файла hosts. Скрипт находит самые быстрые IP-адреса через Smart DNS и объединяет их с актуальными списками блокировки рекламы и телеметрии.

🚀 Возможности
Smart DNS Resolution: Опрашивает 9+ провайдеров (Comss, Xbox, Astra и др.) и выбирает IP с минимальным пингом.

Интерактивные модули:

Adobe Block: Загрузка актуального списка для обхода проверки лицензий.

Mega AdBlock: Объединение списков EasyList, EasyPrivacy, StevenBlack, AdGuard и Peter Lowe.

Умная дедупликация: Исключает повторы доменов, даже если они встречаются в нескольких списках одновременно.

Кроссплатформенность: Полноценные версии для Windows (.bat) и macOS (.command).

Удобство: Автоматически открывает нужные папки для ручной замены файла.

🛠 Инструкция по использованию
Для Windows
Разместите run.bat и ваш domainlist.txt в одной папке.

Запустите run.bat.

Следуйте инструкциям в консоли (используйте Y или N для выбора модулей).

По завершении откроются два окна проводника:

Скопируйте созданный hosts_merged.txt.

Вставьте его в папку etc, удалив старый файл hosts и переименовав новый в hosts.

Для macOS
Разместите run.command и domainlist.txt в одной папке.

Откройте Терминал и дайте права на запуск (нужно сделать один раз):
chmod +x /путь/к/файлу/run.command

Запустите run.command двойным кликом.

После работы скрипт подсветит готовый файл в Finder и откроет системную папку /etc.

Перетащите содержимое в системный hosts (потребуется пароль администратора).

📂 Структура проекта
run.bat — скрипт для Windows (PowerShell Hybrid).

run.command — скрипт для macOS (Zsh).

domainlist.txt — ваш список доменов для резолва (каждый с новой строки).

hosts_merged.txt — итоговый результат (генерируется автоматически).

⚖️ Дисклеймер
ПО предоставляется «как есть» (AS IS).

Не является VPN: Инструмент не шифрует трафик и не скрывает ваш IP. Это автоматизированный nslookup + ping для оптимизации маршрутов.

Ответственность: Автор не несет ответственности за стабильность работы ваших приложений после изменения файла hosts. Всегда делайте бэкап оригинала!

Прозрачность: Скрипт использует только открытые источники списков блокировки и стандартные системные утилиты.

DNS Cache: После замены файла рекомендуется выполнить ipconfig /flushdns (Windows) или sudo killall -HUP mDNSResponder (macOS).
