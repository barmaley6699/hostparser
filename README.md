# 🌐 Multi-DNS Hosts Parser 

Ультимативный инструмент для автоматизации создания файла `hosts` в Windows. Скрипт находит рабочие IP-адреса через Smart DNS, распределяет нагрузку между провайдерами и собирает итоговый файл с **полным сохранением структуры** вашего исходного списка.

## 🚀 Возможности
- **Smart DNS Resolution:** Опрашивает 6+ провайдеров (GeoHide, Comss, Xbox, Astra и др.) и выбирает рабочие IP-адреса.
- **Распределение нагрузки (Load Balancing):** Из доступных прокси-IP выбирается случайный рабочий вариант, чтобы предотвратить перегрузку одной ноды.
- **Умное наследование (Smart Inheritance):** Если IP для поддомена не найден, скрипт автоматически подставляет IP родительского домена.
- **Bruteforce Mode:** Для критичных доменов (из `core_domains.txt`) скрипт перебирает все известные прокси, если стандартный резолв не сработал.
- **HTTP Валидация:** Проверка доступности по HTTP-коду. Ответы `403`, `405`, `451` считаются успехом (сервер доступен и SNI-прокси пропускает соединение).
- **Safe Output:** Защита от крашей на спецсимволах (`{}`) и строгая фильтрация мусорных IP (отбрасывает `1`, `2`, `3` и т.д.).
- **Deep Scan (crt.sh):** Опциональный поиск скрытых поддоменов через публичные сертификаты (таймаут 45с).
- **Adobe Blocklist:** Опциональная загрузка актуального списка блокировки телеметрии Adobe.
- **Совместимость:** Полная поддержка PowerShell 5.1 (встроен в Windows 10/11). Тернарные операторы и новый синтаксис не используются.

## 🛠 Инструкция по использованию

### Для Windows
1. Разместите файлы в одной папке:
   - `run_dns_parser.bat` (скрипт)
   - `domainlist.txt` (ваш список доменов **с комментариями и разделами**)
   - `core_domains.txt` (список доменов для приоритетной проверки/брутфорса)
2. Запустите **run_dns_parser.bat**.
3. Следуйте инструкциям в консоли (выбор опций Y/N):
   - **Блокировка Adobe?** — добавит ~400+ доменов Adobe на `127.0.0.1`.
   - **Deep Scan (crt.sh)?** — найдет скрытые поддомены через публичные сертификаты (медленно, ~45с на домен).
   - **Открыть папку после завершения?**
4. Скрипт создаст файл `hosts_merged.txt`.
   - Файл будет иметь ту же структуру (разделы `# --- QwenAI ---`, `# --- OpenAI ---` и т.д.), что и `domainlist.txt`.
5. Откройте системный файл hosts: `%SystemRoot%\System32\drivers\etc\hosts`.
6. Замените его содержимое на содержимое из `hosts_merged.txt` и сохраните.
7. Сбросьте DNS кэш командой в терминале: `ipconfig /flushdns`.

## 📂 Структура проекта
- `run_dns_parser.bat` — основной скрипт (PowerShell Hybrid, v8).
- `domainlist.txt` — исходный список доменов. **Рекомендуется** использовать структуру с комментариями `# --- Название ---`, она сохранится в итоге.
- `core_domains.txt` — список доменов для жесткой проверки (Bruteforce). Если файл отсутствует, проверяются стандартные сервисы.
- `hosts_merged.txt` — итоговый результат (генерируется автоматически).

## ⚖️ Дисклеймер

**ПО предоставляется «как есть» (AS IS).**

1. **Не является VPN:** Инструмент не шифрует трафик и не скрывает ваш реальный IP. Это сетевой помощник для оптимизации маршрутов через DNS-SNI прокси.
2. **Ответственность:** Автор не несет ответственности за стабильность работы ваших приложений. Всегда делайте бэкап оригинала файла `hosts` перед изменениями!
3. **Безопасность:** Скрипт автоматически отфильтровывает мусорные записи и невалидные IP, но всегда проверяйте итоговый файл перед применением.
4. **Стабильность прокси:** DNS-SNI провайдеры могут изменять IP, вводить капчу или блокировать IP при высокой нагрузке. Скрипт лишь агрегирует публично доступные данные и не гарантирует 100% аптайм сторонних узлов.
