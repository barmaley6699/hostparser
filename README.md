# 🌐 Multi-DNS & AdBlock Hosts Parser

Ультимативный кроссплатформенный инструмент для автоматизации создания файла `hosts`. Скрипт находит самые быстрые IP-адреса через Smart DNS и объединяет их с актуальными списками блокировки рекламы, телеметрии и вредоносных сайтов.

## 🚀 Возможности
- **Smart DNS Resolution:** Опрашивает 9+ провайдеров (Comss, Xbox, Astra и др.) и выбирает IP с минимальным пингом для ваших доменов.
- **Адаптивный ввод:** Понимает ответы на русском и английском (Y/N, Д/Н) и нечувствителен к регистру.
- **Интерактивные модули:**
    - **Adobe Block:** Загрузка актуального списка для блокировки серверов проверки лицензий.
    - **Mega AdBlock:** Агрегация списков EasyList, EasyPrivacy, StevenBlack, AdGuard, Peter Lowe и Malicious URL Blocklist.
- **Умная дедупликация:** Исключает повторы доменов, предотвращая раздувание файла `hosts`.
- **Кроссплатформенность:** Полноценные версии для **Windows (.bat)** и **macOS (.command)**.

## 🛠 Инструкция по использованию

### Для Windows
1. Разместите `run.bat` и ваш `domainlist.txt` в одной папке.
2. Запустите **run.bat**.
3. Следуйте инструкциям в консоли для выбора модулей.
4. По завершении откроются два окна проводника:
   - Скопируйте созданный `hosts_merged.txt`.
   - Вставьте его содержимое в системный файл `%SystemRoot%\System32\drivers\etc\hosts`.
5. Вернитесь в окно скрипта и подтвердите **FlushDNS** для сброса кэша.

### Для macOS
1. Разместите `run.command` и `domainlist.txt` в одной папке.
2. Дайте права на запуск (выполните один раз в Терминале):
   `chmod +x /путь/к/папке/run.command`
3. Запустите **run.command** двойным кликом.
4. После работы скрипт подсветит готовый файл в Finder и откроет папку `/etc`.
5. Перенесите данные в системный `hosts` (потребуется пароль администратора).
6. Подтвердите очистку кэша в окне терминала.

## 📂 Структура проекта
- `run.bat` — скрипт для Windows (PowerShell Hybrid).
- `run.command` — скрипт для macOS (Zsh).
- `domainlist.txt` — ваш список доменов для резолва (каждый домен с новой строки).
- `hosts_merged.txt` — итоговый результат (генерируется автоматически).

## ⚖️ Дисклеймер

**ПО предоставляется «как есть» (AS IS).**

1. **Не является VPN:** Инструмент не шифрует трафик и не скрывает ваш реальный IP. Это сетевой помощник для оптимизации маршрутов.
2. **Ответственность:** Автор не несет ответственности за стабильность работы ваших приложений. Всегда делайте бэкап оригинала файла `hosts` перед изменениями!
3. **DNS Cache:** Рекомендуется всегда подтверждать сброс кэша в конце работы скрипта, чтобы изменения вступили в силу мгновенно.
